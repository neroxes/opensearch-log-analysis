# OpenSearch Log Analysis

Sample log analysis with OpenSearch: indexing, searching and aggregation.

## What this project shows

- Installing OpenSearch and OpenSearch Dashboards with Docker
- Indexing sample security logs
- Searching logs to find failed logins
- Counting failed logins per IP address with an aggregation
- Finding a likely brute-force attack on the `admin` account
